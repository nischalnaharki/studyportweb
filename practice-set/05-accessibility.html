Build for everyone

The four principles

  • Perceivable — content can be seen or heard
  • Operable — everything works with a keyboard
  • Understandable — labels and errors are clear
  • Robust — works with screen readers and future browsers

Six common barriers

1. Images without useful alt text

2. Inputs without labels

3. Low contrast text

Wrong: light grey on white — hard to read on a phone outside.

Right: dark text on a light background (aim for a contrast ratio of 4.5 : 1).

4. Colour as the only signal

Wrong: "Spicy dishes are in red." · Right: 🌶 Spicy — an icon AND a word.

5. Vague link text

Wrong: "For the menu, click here." · Right: See the full menu.

6. Hidden keyboard focus

Wrong CSS: *:focus { outline: none; } — keyboard users get lost. Right: keep the outline, or style a clearly visible one (see the red ring when you Tab).
